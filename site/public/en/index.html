A Minecraft launcher that doesn’t look like a form.

Lumen installs vanilla, Fabric, Quilt, Forge, NeoForge, modpacks and mods like any other launcher. It just doesn’t show your instances as a table, but as an art book, a console home screen, a bookshelf or a CRT monitor. With mouse, keyboard or controller.

Free and open source (GPL-3.0) · Windows 10/11 · no ads, no tracking

Why Lumen exists

The launchers I’ve used all look the same: a list on the left, a pile of settings on the right. They work, but nobody enjoys opening them.

The idea for Lumen comes from ES-DE, a frontend for retro games, and its “Art Book Next” theme, which makes a game collection look like an art book. Lumen is my attempt to build that for Minecraft. It’s a hobby project, the code is open on GitHub, and bug reports and ideas there are very welcome.

What Lumen handles for you

Lumen sets up versions, loaders, libraries, assets and Java itself. You pick what you want to play.

Instances for every version
Vanilla, Fabric, Quilt, Forge or NeoForge, from 1.8.9 to the latest release, with snapshots if you want them. Every instance has its own worlds and mods, its own memory, Java arguments and cover image, and counts its playtime.
Java sorts itself out
Lumen knows which Java a Minecraft version needs (8, 17, 21 or 25), uses an installed one or downloads the right one from Eclipse Temurin.
Modpacks from Modrinth
Pick a pack, pick a version, install. Every file is checked against its checksum, and Lumen applies the pack’s config.
Mods, resource packs, shaders
Search, install and remove them per instance, matching the version and loader. Dependencies like Fabric API come along automatically, and Iris for shaders.
Moving over from other launchers
Lumen brings over instances from the official launcher, Prism, CurseForge, ATLauncher and the Modrinth App, with worlds, mods and settings. The other launcher stays as it is.
Sharing
Export an instance as a .mrpack for friends, and import .mrpack files in one click.
Updates
Update outdated mods one by one or all at once, always to the newest stable version. Lumen keeps itself up to date too.
Controller
Browse with the d-pad, launch with A, go back with B. Plug in a controller and Lumen shows the matching buttons.
Offline or with Microsoft
Sign in with your Microsoft account and play on any online server, or play offline with a name. Windows stores the login encrypted, and Lumen never sees your password.

Five layouts, each with its own look

Every layout shows the same instances and modpacks, with its own structure, typography and motion. Switch in the settings, and press G any time to get back to the plain grid.

Plus five colour schemes

Colours are independent of the layout: a bright art book with a serif typeface, synthwave, a blocky game menu on dirt, or Swiss print in duotone. Every instance also gets its own accent colour from its icon.

Flip through modpacks

The Discover page pulls modpacks live from Modrinth and shows them in your layout, with gallery image, author, downloads and supported versions.

  • Search as you type. Results appear instantly, and more load as you keep flipping.
  • Install in one step. Lumen creates the instance, downloads every mod and applies the pack’s config.
  • Every common loader. Fabric, Quilt, Forge and NeoForge: Lumen sets up the loader itself.

Mods and updates

Every instance with a mod loader has its own mod browser. Lumen recognises installed mods by the file’s fingerprint, including the ones that came with a modpack.

  • Dependencies come along. Install Iris and Sodium comes with it.
  • Outdated mods at a glance. Old and new version sit right in the list, and one click updates them all.
  • Stable versions only. Updates never jump to a beta or alpha.

Install Lumen

The installer creates shortcuts and keeps Lumen up to date automatically. The ZIP version runs without installing: extract it and start Lumen.exe. It only tells you about new versions; you download them yourself.

Download installer ZIP, no installation

64-bit · about 110 MB · All versions & checksums · Source code

  1. Run the installerPick a folder, done. No admin rights needed.
  2. Create an instance“New instance” for a version of your own, or install a modpack from “Discover”.
  3. PlayOn first launch Lumen downloads Minecraft and the right Java, and after that it starts right away, offline too.

Windows warns you on first launch. Lumen isn’t digitally signed, which would need a paid certificate. When you see “Windows protected your PC”, click More info and then Run anyway.

Questions

Can I play on regular online servers?

Yes. Sign in under Settings → Microsoft account; the sign-in happens in your browser, directly with Microsoft. Without signing in you play offline: in singleplayer and on servers with online-mode=false.

Do I need to own Minecraft?

For the Microsoft sign-in and official servers, yes: Lumen checks that your account owns Minecraft: Java Edition. If you play regularly, please buy the game.

How do I get updates?

The installer version downloads new versions in the background and installs them the next time you start it. The ZIP version shows a notice with a download link.

Are Forge and NeoForge supported?

Yes, since version 0.1.4: NeoForge, and Forge from Minecraft 1.13 on. Lumen downloads and sets up the loader itself, for modpacks too.

Can I move over from another launcher?

Yes. Under “New instance” → “From another launcher”, Lumen finds instances from the official launcher, Prism, CurseForge, ATLauncher and the Modrinth App and copies worlds, mods, packs and settings. The other launcher stays as it is.

Do I have to install Java?

No. Lumen looks for a suitable installed Java and otherwise downloads the right one from Eclipse Temurin.

Where are my worlds and mods?

In %APPDATA%\.lumen, each instance in its own folder under instances. The folder icon on an instance opens it directly. Uninstalling Lumen keeps your data.

Is the app available in German?

Yes. Lumen speaks English and German and follows your system language; you can switch under Settings → Language.

Does Lumen run on Mac or Linux?

Right now only on 64-bit Windows 10 and 11.
