What Lumen does

Everything a launcher needs. Nothing that gets in the way.

Lumen takes care of versions, loaders, libraries, assets and Java. You just pick what you want to play.

Instances for every version

From the classic 1.8.9 to the latest release, plus snapshots and older versions if you want – vanilla, with Fabric or with Quilt. Every instance has its own worlds, mods and settings and never gets in another one’s way.

VanillaFabricQuiltSnapshotsSeparate worlds

Java sorts itself out

Lumen knows which Java a Minecraft version needs – 8, 17, 21 or 25 – and uses an installed one or downloads it automatically. No hunting around, no error messages.

Modpacks in one click

Browse thousands of modpacks from Modrinth, pick a version, done. Lumen sets up the mods, config and loader.

A mod browser per instance

Search, install and remove mods that match the version and loader. Required dependencies like Fabric API come along automatically.

Updates without the risk

Lumen spots outdated mods and updates them one by one or all at once – always to the newest stable version, never to a beta.

Built for the couch

Browse with the d-pad, launch with A, go back with B, switch views with Y. Lumen works just as well with a controller as with mouse and keyboard – the on-screen hints adapt automatically.

Offline or with Microsoft

Play right away with an offline name – in singleplayer and on your own servers. Optionally sign in with your Microsoft account; the login is stored encrypted by Windows.

Five layouts

Not five colours. Five UI languages.

Inspired by frontends like ES-DE: every layout shows the same instances and modpacks in a completely different visual language. Switch any time in the settings – or press G to go back to the classic grid.

Layout · Art Book

One double-page spread per instance: the picture on the left as a plate with a caption, a big title on the right, key facts like a figure legend and the play button. The page colour comes from the icon.

Get started

Three steps to playing.

Install

Run the Lumen installer, pick a folder – done. Desktop and Start menu shortcuts included.

Create an instance

“New instance” for a version of your own, or install a modpack from “Discover”.

Play

On first launch Lumen downloads Minecraft and the right Java. After that everything starts instantly – offline too.

FAQ

Frequently asked questions

Can I play on regular online servers?

For that you need the Microsoft account sign-in that Lumen has built in. It works as soon as Microsoft approves the launcher’s Azure app for the Minecraft API – that’s in progress. Until then you play offline: in singleplayer and on servers with online-mode=false, such as your own server with friends.

Do I need to own Minecraft?

For the Microsoft sign-in and official servers, yes – Lumen checks that your account owns Minecraft: Java Edition. Please support the developers and buy the game if you play it regularly.

Is the app available in English?

Yes. Lumen speaks English and German and follows your system language by default; you can switch any time under Settings → Language.

Are Forge and NeoForge supported?

Not yet. Lumen supports vanilla, Fabric and Quilt. Modpacks that need Forge or NeoForge are marked on the Discover page.

Do I have to install Java?

No. Lumen looks for a suitable installed Java and otherwise downloads the right one (Eclipse Temurin) automatically – Java 8 for old Minecraft versions, 21 or 25 for new ones.

Where are my worlds and mods?

Everything lives in %APPDATA%\.lumen: each instance in its own folder under instances, with worlds, mods and settings. The folder icon on an instance opens it directly. Uninstalling Lumen keeps your data.

Does Lumen run on Mac or Linux?

Right now only on 64-bit Windows 10/11.

Does Lumen cost anything?

No. Lumen is a free hobby project with no ads and no tracking.
